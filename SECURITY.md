# Security

This is a static personal site and a set of published studies. It has no login, no database and no user data.

If you find a security problem in the site or in its build, please report it privately through GitHub: **Security > Report a vulnerability** on this repository. Please don't open a public issue for it.

I'll answer as soon as I can. For the studies, if you spot a mistake in a figure or in the method, a normal issue is welcome.
